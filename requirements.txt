# Pinned requirements for the GemseoProcessBuilder environment.
#
# The package is NOT published on PyPI (SPEC § 14.5): it is installed straight
# from the GitHub repository, like its two plugins.
#
# Pins were frozen from a working environment running Windows, Python 3.12
# (the reference development version, SPEC § 14.4) and Node.js 22 for the
# JavaScript tests. The JavaScript side needs no npm package: d3 and elkjs are
# vendored under gemseo_process_builder/static/vendor/.
#
# Red Hat Enterprise Linux 9 (glibc 2.34, x86_64): this exact set installs as
# is -- audited against PyPI on 2026-09-28, nothing blocked, nothing to
# downgrade. The tightest wheels are the Qt ones: PySide6 6.11.2, shiboken6,
# PySide6_Essentials and PySide6_Addons need glibc 2.34 exactly, which is what
# RHEL 9 provides. Take Python 3.12 from AppStream (python3.12 plus the
# python3.12-pip subpackage); the system python3.9 is below requires-python.
# requirements-compat.txt holds the same set with upper bounds, for a machine
# whose index only offers older releases.
#
# Usage, from the repository root:
#   Windows: .venv\Scripts\python.exe -m pip install -r requirements.txt
#   Linux:   .venv/bin/python -m pip install -r requirements.txt
#
# Inside a clone, replace the three lines below with the local editable
# installs used for development (they follow the working tree instead):
#   -e .
#   -e plugins/gemseo_lso
#   -e plugins/gemseo_claude_pilot
#
# Regenerate the pinned list with: python -m pip freeze
