# 24 — N2 view

Status: Not started
Depends on: 11
SPEC: § 8.4, § 14.1 (N2 performance)

## Goal

Add the N2 matrix view of a scope, built from the resolver, rendered in SVG with virtualization so it stays fluid on very large models.

## Scope

In:
- Bridge method `n2.build(scope)`: ordered diagonal entries (components and collapsible containers), off-diagonal cells with coupled variable lists, hierarchy blocks. Computed in the UI process from the resolver (no GEMSEO).
- N2 center tab with its own zoom/pan, following the current canvas level by default (toggle "Follow canvas").
- Hierarchical blocks: collapse/expand an assembly or driver on the diagonal; collapsed entries aggregate their couplings.
- Cell interaction: hover highlights row/column; click shows the coupled variables in the inspector (and selects the producer and consumer on the canvas).
- Reordering by drag and drop on the diagonal: in `chain` assemblies it changes the execution order (a command); elsewhere it is a display order stored in the layout (non-undoable).
- Feedback cells (below the diagonal) in the feedback color.
- Virtualized rendering: only visible cells are in the DOM; below a zoom threshold, cells become plain colored squares without labels (level of detail).
- "Show in N2" context-menu action from canvas and tree.

Out:
- Performance tuning against the 2,000-component target (plan 32), image export (plan 31).
