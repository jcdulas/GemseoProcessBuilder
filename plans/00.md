## Goal

Create the repository, the Python package skeleton, the development environment and the quality tooling, so that every later plan can run `python tools/check.py` and get a green result.

## Context

- The folder contains `SPEC.md`, `CLAUDE.md`, `LICENSE` (MIT) and `plans/`. It is a git repository (branch `main`) whose remote `origin` is https://github.com/jcdulas/GemseoProcessBuilder.git.
- The project is open source under the MIT license (SPEC § 14.6).
- The machine has Python 3.13 (`C:\Python313\python.exe`, the default `python`), Python 3.12 (`C:\Python\Python_3_12\python.exe`), Node 22 and git. No conda, no uv.
- The project uses **Python 3.12** for development.
- GEMSEO and PySide6 are not installed.

## Scope

## Steps

- [ ] Add `.gitignore` (venv, caches, `*.runs/`, `*.surrogates/`, `*.autosave`, `.mypy_cache`, `node_modules`) and `.gitattributes` (`* text=auto eol=lf`, binary types).
- [ ] Create the development venv with **Python 3.12** (decided by the user): `C:\Python\Python_3_12\python.exe -m venv .venv`. Document it in `README.md` (Linux: `python3.12 -m venv .venv`). 3.12 is both the minimum supported version and the reference development version (SPEC § 14.4).
- [ ] Write `pyproject.toml`:
  - project name `gemseo-process-builder`, `requires-python = ">=3.12"`;
  - `license = "MIT"`, `license-files = ["LICENSE"]` (the `LICENSE` file already exists at the root), author and classifier `License :: OSI Approved :: MIT License`;
  - dependencies: `gemseo>=6,<7`, `PySide6>=6.6`, `pydantic>=2`, `pint`, `psutil`;
  - optional `dev`: `pytest`, `pytest-timeout`, `ruff`, `mypy`;
  - optional `xdsm`: `pyxdsm`;
  - script entry point `gemseo-process-builder = "gemseo_process_builder.__main__:main"`;
  - hatch build config including `gemseo_process_builder/static/**`.
- [ ] Install in editable mode: `pip install -e ".[dev]"`.
- [ ] Configure ruff in `pyproject.toml`: line length 88, target the minimum Python version, rule set `E, F, W, I, N, UP, B, SIM, RUF, D` (Google docstring convention, docstrings required on public API only), `ruff format`.
- [ ] Configure mypy: `strict = true` for `gemseo_process_builder`, `ignore_missing_imports` for `gemseo.*` and `PySide6.*` only if needed.
- [ ] Configure pytest: `testpaths = ["tests/python"]`, `timeout = 1`, `timeout_method = "thread"`, `addopts = "--durations=10 -q"`.
- [ ] `tests/python/conftest.py`: import `gemseo` and `PySide6.QtWidgets` at module level (collection time) and create one `QApplication` instance, with a comment explaining the one-second rule (SPEC § 15.1).
- [ ] `tests/python/test_package.py`: version test, and a test that deliberately sleeps 1.5 s marked `@pytest.mark.skip(reason="manual check of the timeout")`. Run it once unskipped by hand to confirm the timeout fails it, then keep it skipped.
- [ ] `package.json` with `"type": "module"` and `"scripts": { "test": "node --test --test-timeout=1000 tests/js" }`.
- [ ] `tests/js/smoke.test.js` using `node:test` and `node:assert`.
- [ ] `tools/check.py`: runs in sequence `ruff check .`, `ruff format --check .`, `mypy gemseo_process_builder`, `pytest`, `node --test --test-timeout=1000 tests/js`; prints a summary table; exits non-zero if any step fails. Option `--fix` runs `ruff check --fix` and `ruff format` first.
- [ ] `README.md`: purpose (one paragraph linking to SPEC.md), setup commands for Windows and Linux, how to run the checks and the app, and a "License" section (MIT, link to `LICENSE`).

## Tests

- `test_package.py`: `gemseo_process_builder.__version__` is a string.
- `smoke.test.js`: trivial assertion to prove the runner works.

## Acceptance criteria

- `python tools/check.py` passes on a fresh clone after following the README.
- The total pytest run (including the GEMSEO import at collection) completes with every test under one second.
- `python -m gemseo_process_builder` prints the version.
