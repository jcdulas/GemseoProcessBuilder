# 20 — Results views I: summary, history, table

Status: Not started
Depends on: 18, 19
SPEC: § 12.2 (Summary, History, Data table), § 11.5 (live history)

## Goal

Open a Results tab per run with the Summary, History and Data table views, working both for finished runs and live during a run (replacing the live chart of plan 18).

## Scope

In:
- Results tab framework: one center tab per opened run, with sub-tabs; opened from the Runs panel, automatically when a run starts, and restored for the last opened run.
- **Summary**: status, duration, evaluations, optimum (design variables, objectives, constraints with active/violated indicator and margin), best feasible point, algorithm and formulation used, link to the script.
- **History**: objective, constraints (with threshold line), normalized design variables vs. iteration; log/linear toggle; hover readout; live updates during a run.
- **Data table**: virtualized table backed by `results.rows` paging, sort, filter builder, column chooser, CSV export of the current view.
- Chart component basics reused by plan 21: axes, scales, tooltip, legend, resize handling.

Out:
- Scatter matrix, XY, parallel coordinates, parametric views, comparison (plan 21).

## Design

- Load the `dataviz` skill before writing chart code; colors come from CSS tokens.
- Live mode: the History view reads from the run state service of plan 18; after `run.finished` it switches to worker-backed data transparently.
- The Data table requests pages ahead of the scroll position (one page of prefetch each way).
