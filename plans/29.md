# 29 — Executable wrapper editor

Status: Not started
Depends on: 28
SPEC: § 7.5 (graphical editor, test run, reusable descriptor)

## Goal

Let users wrap an external code graphically: mark input values in a sample input file, select output values in a sample output file, test the wrapper, and save it as a reusable descriptor.

## Scope

In:
- Wrapper editor opened full-panel from an `executable` component (inspector button "Open wrapper editor") or from `Tools › New executable wrapper…`. Tabs:
  1. **Command**: executable picker, arguments with token insertion, environment variables, timeout, working directory policy, files to copy.
  2. **Inputs**: load a sample input file; text view with line numbers; selecting a number (or a range for a vector) → "Make variable" (name, format guessed from the selected text, unit, description) → the text is replaced by a highlighted `{{name:format}}` marker; list of markers with edit/delete; several input files supported.
  3. **Outputs**: load a sample output file; selecting a value → proposes a rule (marker-based by default, regex as an alternative) with a live preview of the extracted value on the sample; table rule from a selected block; list of rules with preview status.
  4. **Test run**: fill input values (defaults from the sample), run the wrapper in the worker, show extracted outputs, stdout/stderr, return code, working directory (with "Open folder").
- Ports of the component updated from the markers and rules (through `setPorts` in the same transaction as the config change).
- Save as descriptor (`.gpbwrap.json`) into a catalog folder; "Detach from descriptor" to edit an inline copy.
- Worker method `executable.test_run(spec, inputs)`.

Out:
- Nothing else; this completes § 7.5.

## Deliverables

## Design

- The text views are plain `<pre>` elements with spans for markers; files up to 5 MB are loaded, larger files show only the first 5 MB with a warning.
- Rule suggestion prefers the closest preceding text on the same line as the marker; regex suggestions escape literal text and capture a number pattern.
