# 07 — Model tree and inspector

Status: Not started
Depends on: 06
SPEC: § 8.3, § 8.7

## Goal

Add the Model tree (left panel) and the Inspector (right panel) with their base content, both synchronized with the canvas selection, and a reusable virtualized list component for large models.

## Scope

In:
- Virtualized list component (fixed row height) used by the tree and, later, by tables.
- Tree: Model › assemblies/drivers › components › ports; expand/collapse; selection sync with the canvas; inline rename; drag and drop to re-parent (`reparentNodes`); the context menu framework of plan 06.
- Inspector:
  - **Properties** section: name, description, type/kind (read-only), assembly mode (`auto | chain | parallel | mda`), `isolated`, `transparent` flags (stored now, used by later plans).
  - **Variables** section: virtualized table of ports (local name, direction, dtype, shape, unit, default, description), editable through `setPorts`; filter and sort.
  - Multi-selection: shows the common fields only.
- "Show in tree" / "Show in canvas" actions.

Out:
- Component-specific configuration editors (plan 10), global names and roles columns (plans 11, 15), driver editor (plan 15), link inspector (plan 12).

## Deliverables

## Design

- Row height fixed (22 px) so virtualization stays a pure computation; overscan of 10 rows.
- The tree keeps its own expanded set (persisted in the project layout as `tree_expanded`) and auto-expands to reveal the selection.
- Editing a cell sends a command; the cell shows a transient error state if the command fails (message from the bridge error).
- Values are parsed in `table_model.js`: numbers, `[1, 2, 3]` arrays, shapes like `3` or `3x4` → `[3, 4]`.

- `tree_flatten.test.js`: collapsed branches hidden, depth values, reveal path of a deep node.

## Acceptance criteria

- Selecting in the tree selects on the canvas and vice versa; the inspector follows.
- A tree with 10,000 rows scrolls smoothly (manual check with a generated project).
- Port edits are undoable.
- `python tools/check.py` passes.
