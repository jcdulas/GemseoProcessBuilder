# 52 — Checking GEMSEO 6 scripts

Status: Done
Depends on: 51
SPEC: § 4.2.1, § 14.2

## Goal

The reading of scripts works for GEMSEO 6: before a script is run to be read, its code is analysed to make sure it is a GEMSEO 6 study, and not a study for an earlier version, or another program (the user's request).

## Scope

In:
- `workers/script_check.py`: the static check of a script and of the modules of its folder it imports;
- `read_script` refusing, without running it, a script that fails the check;
- the worker refusing a GEMSEO whose major version is not 6;
- the page showing the reasons one per line.

Out:
- Converting a GEMSEO 5 study to GEMSEO 6.

## Steps

- [x] Imports of `gemseo` checked against the installed GEMSEO 6, with hints.
- [x] Calls and attributes of the API of GEMSEO 5.
- [x] Local modules, recursively; files that are not valid Python.
- [x] The reader and the worker; the page.
- [x] Tests, SPEC, guide, changelog.

## Tests

- pytest:
  - the hand-written GEMSEO 6 scripts accepted (and, checked by hand, the examples and golden scripts);
  - a GEMSEO 5 study refused with a hint for each line;
  - another program, and a file that is not valid Python;
  - a GEMSEO 5 module imported by a local module, found through it;
  - a refused script not run (a file it would write is not written);
  - GEMSEO versions accepted and refused.

## Acceptance criteria

- No example, golden or hand-written GEMSEO 6 script is refused.
- `python tools/check.py` passes.

## Implementation notes

- **Checking names by importing GEMSEO modules**: the names are checked with `importlib` against the GEMSEO installed in the worker, which is always GEMSEO 6 now. This covers every rename, not only a list; the lists of the module only give hints. Only GEMSEO modules are imported: user code is never run by the check.
- **Speed**: with GEMSEO loaded, as in the worker, the 29 known scripts are checked in 0.1 s.
- **Hints**: a renamed module that was also split since (`gemseo.problems.sellar.sellar`) points to the package holding its parts (`gemseo.problems.mdo.sellar`).
- **`local_data`** still exists in GEMSEO 6: it is not reported.
- The toast after reading a script no longer tells to save as a project to keep the layout (plan 48): it says the diagram is laid out.
